# DevInfinity — доска проектов и команд

## Назначение приложения

DevInfinity — площадка, где авторы публикуют идеи проектов, а разработчики
находят эти проекты по интересам и присоединяются к командам.

Основная проблема, которую решает сервис: проекты часто не доходят до релиза
из-за сложности поиска соучастников с нужными навыками.
DevInfinity соединяет идею и команду:

- автор размещает проект с описанием и тегами;
- автор указывает, какие роли команда ищет (статус «Ищем команду»,
  «Формируемся» или «В работе»);
- участники ищут проекты по тегам (React, Python, ML/AI и др.) и ролям;
- участники подают заявку в понравившуюся команду.

## Основные пользовательские сценарии

1. **Просмотр ленты проектов.** Пользователь открывает раздел «Проекты»
   и видит карточки идей с тегами, статусами и открытыми ролями.
2. **Поиск проектов по тегам и ролям.** Пользователь фильтрует карточки по
   интересующей технологии или роли, которую готов закрыть.
3. **Детали проекта.** Пользователь открывает проект, знакомится с описанием,
   составом команды и открытыми ролями.
4. **Подача заявки в команду проекта.** Пользователь нажимает «Подать заявку»;
   на текущем этапе действия выполняются с демонстрационными данными.
5. **Просмотр команд.** Пользователь изучает собранные команды, открывает
   карточку команды, видит её состав (участников) и количество искомых людей,
   затем откликается на открытые роли.
6. **Вход и регистрация.** Пользователь создаёт аккаунт или входит в него
   (демо-режим без backend). После входа в шапке появляется аватар, по клику
   на который открывается профиль.
7. **Профиль.** Пользователь просматривает данные аккаунта и выходит из него.
8. **Смена темы и языка.** Пользователь переключает светлую/тёмную тему и язык
   интерфейса (русский/английский).
9. **Навигация по разделам.** Переходы между экранами выполняются через
   клиентскую маршрутизацию; на каждой странице есть кнопка «Назад».

## Экраны приложения

| Экран | Маршрут | О чём |
| --- | --- | --- |
| Главная | `/` | Описание сервиса, шаги работы, недавние проекты |
| Проекты | `/projects` | Доска идей: карточки, поиск, фильтры по тегам и ролям |
| Детали проекта | `/projects/:id` | Описание проекта, команда, открытые роли, заявка |
| Команды | `/teams` | Команды, ищущие участников на открытые роли |
| Детали команды | `/teams/:id` | Состав команды, открытые роли, демо-отклик |
| О проекте | `/about` | Цели платформы, возможности, планы развития |
| Вход | `/login` | Форма входа (демо-режим) |
| Регистрация | `/register` | Создание аккаунта (демо-режим) |
| Профиль | `/profile` | Данные аккаунта, выход из системы |
| Не найдено | `*` | Страница 404 |

Скриншоты экранов хранятся в [docs/screenshots](docs/screenshots).

## Технологический стек

- **Frontend:** React 19 + TypeScript, сборка Vite
- **Маршрутизация:** React Router v7 (клиентская, режим `createBrowserRouter`)
- **UI-компоненты:** Ant Design 6 (`antd`, `@ant-design/icons`)
- **Темы:** светлая/тёмная на основе токенов Ant Design (`ConfigProvider`)
- **Локализация:** переключение русского и английского языков (контекст + словари)
- **Состояние:** контексты React (тема, язык, демо-авторизация через `localStorage`)


## Запуск frontend

Требования: Node.js 20+ и npm.

```bash
# из корня репозитория
cd frontend
npm install        # установка зависимостей (при первом запуске)
npm run dev        # запуск dev-сервера
```

Приложение будет доступно по адресу <http://localhost:5173>.

Полезные команды:

```bash
npm run build      # проверка типов (tsc) и продакшен-сборка в dist/
npm run preview    # локальный просмотр продакшен-сборки
npm run lint       # статическая проверка кода (oxlint)
```
